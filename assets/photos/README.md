# Photos

Drop your photos into this folder.

To match the site's layout perfectly:
- Recommended dimensions: 800x800 for square (like profile photos).
- Supported formats: WebP, JPEG, PNG.

Only `about.md` is wired so far, with placeholder logic to include your images when they are added.

- `assets/photos/profile-home.webp` (Used on the Homepage)
- `assets/photos/profile-about.webp` (Used on the About page)
